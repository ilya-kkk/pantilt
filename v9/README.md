# PanTilt V9

See [the Russian assembly and printing guide](README_RU.md) and [bill of materials](BOM_RU.md).

V9 splits the previous monolithic parts into 21 printable parts with M3 DIN 912 screws and side-fed ordinary nuts. The fixed pan motor is now below the rotating platform. Bearings: 3×608 and 1×51107. Reductions: GT2 120:20 and 80:20, 10 mm belts.

Run `build_v9.py` with FreeCAD Python, then `inspect_v9.py`. `finish_cad.py` adds native display styling and a separate calibration coupon. See the Russian guide for fit assumptions and validation limits. This is an unprinted engineering prototype, not a physically qualified product.
